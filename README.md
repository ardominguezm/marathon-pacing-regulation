# Marathon Pacing Regulation

**Working paper:** *Quantifying Pacing Regulation in Marathon Running: A Field-Derived Functional and Its Information Horizon*

Reproducible analysis and manuscript repository for a population-scale field-methods study of marathon pacing regulation across Berlin, Boston, Chicago, and New York City.

## Main result

Using 551,337 finishers across 16 race-year cohorts, an order-sensitive quadratic pacing-regulation functional showed essentially no reproducible information about subsequent late-race performance at 15 km, a consistent signal by approximately 20 km, and markedly stronger information by 25 km. The same information-horizon classification survived a confirmatory analysis using absolute 30–40-km velocity conditional on early velocity, reducing concern about ratio-outcome coupling.

## Functional

For normalized segment velocity $r(x)$,

$$
\mathcal{R}(x)=\frac{1}{m(x)}\sum_{j\le m(x)}[r(x_{j+1})-r(x_j)]^2.
$$

APRC is a mathematical descriptor of local pacing roughness/regulation. It is **not** interpreted as thermodynamic entropy production, metabolic energy expenditure, Joules, kcal, or direct physiological work.

## Final figure workflow

`notebooks/04_final_EJAP_figures.ipynb` is Colab-compatible after cloning this repository. It generates the final EJAP-oriented figure set with restrained typography, white background, minimal chart ink, concise in-panel annotations, vector PDF/SVG output, and 600-dpi PNG output.

The planned main set is: conceptual framework; information horizon; 16-cohort replication; spatial progression; performance-stratified information curves; and confirmatory outcome de-coupling. APRC beyond same-horizon CV is supplementary.

## Reproducibility and data

Frozen aggregate outputs required for the publication figures are versioned in `data/processed_results/`. Individual participant-level records are not redistributed. Source-data provenance and acquisition procedures should be documented separately before public release.
